# Mohan-Game — Production Roadmap\n\n## Current playable slice\n- Procedural 3D city/grid with roads, buildings, windows and ground.\n- Third-person camera with damping.\n- Original player character with movement, sprint and jump.\n- Drivable vehicles with acceleration, steering and enter/exit.\n- Pedestrian NPCs with panic behavior.\n- Forward projectile shooting, ammo and reload.\n- Wanted meter and HUD.\n- Dynamic lighting/day-cycle prototype.\n- Lightweight particle feedback.\n\n## Production architecture\nThe prototype is deliberately dependency-light so it can run as a static site. For AAA scope, evolve it into a data-driven engine with these boundaries:\n\nGameBootstrap -> WorldStreaming -> PlayerController -> CameraController -> VehicleSystem -> PedestrianAI -> CombatSystem -> MissionSystem -> WantedSystem -> UI/HUD -> SaveSystem\n\n## Next milestones\n1. Replace primitive geometry with original/licensed GLB assets and PBR materials.\n2. Add streamed world sectors, interiors and collision/navmesh.\n3. Add traffic AI, police AI, combat cover, damage, ragdolls and better animation.\n4. Add mission scripting, checkpoints, objectives, dialogue and fail/retry flow.\n5. Add shops, garages, inventory, economy, weapons and vehicle customization.\n6. Add save/load, pause/settings, accessibility and controller support.\n7. Profile GPU/CPU/memory and add LOD, instancing, culling and asset compression.\n8. Add automated smoke tests and deployment.\n\n## Scope note\nMohan-Game can target the feature class of a modern open-world action game, but it should remain an original IP. GTA V characters, map, missions, dialogue, branding, models, textures, audio and other copyrighted assets should not be copied into this repository.
