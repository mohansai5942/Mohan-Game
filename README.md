# Mohan-Game

A browser-based original 3D open-world action game prototype inspired by the scope and freedom of modern open-world games.

## Play
Open `index.html` in a modern desktop browser, or serve the repository with any static HTTP server.

## Controls
- WASD — move / drive
- Shift — sprint / boost
- Mouse — camera / aim
- Left click — shoot
- E — enter/exit vehicle
- F — interact
- Space — jump / handbrake
- R — reload
- Esc — release mouse

## Architecture
Vanilla HTML/CSS/JavaScript + Three.js loaded from a CDN. All gameplay systems are modularized under `src/`.
